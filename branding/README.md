# 브랜드

**선택: 2 이적 경로** (2026-10-15). 로고 체계, 색, 글꼴, 문장, 적용 예시, 파일 규칙은 **[브랜드 가이드](guide.md)**에 있고, 내보내기 파일은 [kit/](kit/)에 있습니다.

![가로 로고](kit/png/ktr-logo-h-light@2x.png)

아래는 [브랜딩 요청서](../docs/branding-request.md)의 "방향 제안" 단계 기록입니다. 세 방향을 앱 아이콘, 가로 로고, 스플래시로 비교했습니다. 비교 보드: [index.html](index.html)

## 공통 기준

- **팔레트:** 채택된 배송 조회 화면([docs/design/tokens.css](../docs/design/tokens.css))의 중립색만 씁니다. 잉크 `#121823`, 바탕 `#f4f5f7`, 표면 `#ffffff`, 선 `#dfe2e8`, 보조 잉크 `#434c5c`, 다크 보조 `#8f99a9`.
- **브랜드에 강조색을 두지 않았습니다.** K리그1·2 구단 색이 파랑, 빨강, 노랑, 주황, 보라, 초록, 하늘색을 거의 다 쓰고 있어 어떤 색을 골라도 특정 구단이 떠오릅니다. 그리고 화면의 단계 색(접촉 파랑, 협상 호박, 임박 보라, 결렬 빨강, 공식 확정 초록)과도 겹치지 않아야 합니다. 그래서 브랜드는 잉크 한 색으로 두고, 색은 데이터의 상태에만 씁니다.
- **열린 모양 = 주장, 채운 모양 = 반영·확인:** 화면에서 루머를 점선과 빈 원으로 그리는 규칙을 마크에도 그대로 썼습니다.
- **글꼴:** Pretendard Variable (OFL-1.1). `assets/PretendardVariable.woff2`에 함께 두었습니다.
- **표시명:** "K리그 이적 레이더"를 임시로 썼습니다. 이름은 방향을 고른 뒤 정합니다.

## 콘셉트

| 콘셉트 | 아이디어 | 바탕 |
| --- | --- | --- |
| 1 현재 위치 (`track-now`) | 조회 막대를 그대로 마크로 옮겼습니다. 지나온 구간은 실선, 큰 점은 지금 반영된 위치, 아직 오지 않은 구간은 점선과 빈 원입니다. 앱 화면과 같은 문법이어서 아이콘과 화면이 바로 이어집니다. | 잉크 |
| **2 이적 경로 (`route`) · 선택** | 두 구단을 잇는 점선 호와 그 위의 현재 위치 점입니다. 출발 구단은 채운 원, 도착 구단은 빈 원입니다. 이적 자체를 그린 마크이고, 구단 색을 쓰지 않아 어느 구단에도 치우치지 않습니다. | 밝은 회색 |
| 3 두 개의 따옴표 (`quote`) | 출처의 말을 옮기는 따옴표 한 쌍입니다. 채운 따옴표는 확인된 근거, 빈 따옴표는 아직 주장인 소식입니다. 이적을 "맞히는" 서비스가 아니라 "누가 무엇을 말했는지 보여 주는" 서비스라는 점을 드러냅니다. | 흰색 |

각 방향을 쓸 때 주의할 점:

- **1 현재 위치:** 가로로 긴 형태여서 정사각 아이콘 안에서 세로 여백이 많습니다. 파비콘 16px에서는 점선이 뭉개지므로 실선과 큰 점만 남긴 축약형이 따로 필요합니다.
- **2 이적 경로:** 화살표나 지도 앱처럼 읽힐 수 있습니다. 출발·도착의 채움 차이가 작은 크기에서 잘 보이는지 확인해야 합니다.
- **3 두 개의 따옴표:** 기호가 널리 쓰여서 축구나 이적과 바로 연결되지는 않습니다. 이름과 함께 노출될 때 힘을 얻습니다.

## 파일

```text
branding/
  brand.json                  # 제품명, 기준, 글꼴, 팔레트, 크기, 콘셉트 목록
  index.html                  # 비교 보드 (스크립트가 생성, 직접 고치지 않음)
  assets/PretendardVariable.woff2
  concepts/<id>/
    icon.svg                  # 1024x1024, 배경 꽉 채움, 글자 없음
    logo.svg                  # 가로 로고 440x120, 투명 배경
    splash.html               # ?t=0..1 로 프레임 고정, t 없으면 재생
    export/                   # 생성물: icon-1024/512/192/48.png, logo.png, splash.gif, splash-final.png
```

## 다시 만들기

저장소 루트에서 실행합니다. 헤드리스 Chrome(또는 Playwright Chromium)과 ffmpeg가 필요합니다.

```powershell
node branding/scripts/build-kit.mjs     # 선택안 kit/ 전체
```

방향 시안(`concepts/*/export`, `index.html`)은 station 허브의 `brand-drafts` 스킬 스크립트(`render-brand.mjs`)로 만들었습니다.
