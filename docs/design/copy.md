# 문구표: 배송 조회 화면

화면에 나오는 모든 문구입니다. 구현 시 이 표의 문구를 그대로 쓰고, 새 문구가 필요하면 이 표에 먼저 추가합니다.

## 단계

| 값 (`stage`, `claimed_stage`) | 긴 이름(배지, 이력) | 짧은 이름(역, 꼬리표) |
| --- | --- | --- |
| `unknown` | 단계 미확인 | 미확인 |
| `interest` | 관심설 | 관심 |
| `contact` | 접촉설 | 접촉 |
| `negotiation` | 협상설 | 협상 |
| `near_agreement` | 합의 임박설 | 임박 |
| `confirmed` | 공식 확정 | 확정 |
| `failed` | 결렬설 | 결렬 |

공식 확정 외 모든 단계에는 "~설"을 붙여 주장임을 드러낸다. "확정", "단독", "100%", "예측 적중" 같은 표현을 루머에 쓰지 않는다.

## 신뢰도, 검토 상태

| 값 | 문구 | 툴팁·보조 |
| --- | --- | --- |
| `confidence: low/medium/high` | 신뢰도 낮음 / 보통 / 높음 | "근거 신뢰도: 출처의 독립성과 명확성 기준입니다. 이적이 성사될 확률이 아닙니다." |
| `review_status: unverified` | 미검증 | 아직 사람이 확인하지 않았습니다. |
| `review_status: pending` | 검토 대기 | 모호하거나 상충하는 주장이 있어 확인을 기다립니다. 확인 전까지 기존 단계를 유지합니다. |
| `review_status: reviewed` | 검토 완료 | 운영자가 근거를 확인했습니다. 공식 확정을 뜻하지 않습니다. |
| `review_status: refuted` | 반박됨 | 근거가 사실이 아닌 것으로 확인됐습니다. |

| 보기 필터 | 전체 · 진행 중 · 확정 · 결렬·반박 (뒤에 건수) |
| 섹션 제목 | 영입 {n} · 방출 {n} |
| 묶음 소제목 | 진행 중 · 확정 · 결렬·반박 |
| 상대 구단 없음 | 출발 미상 · 행선지 미상 |
| 검토 중 꼬리표 | {짧은 이름} 주장 검토 중 (예: 결렬 주장 검토 중) |
| 반박 꼬리표 | 반박됨 |
| 필터 결과 없음 | 해당하는 소식 없음 |
| 더 보기 | 30건 더 보기 / 지금 {n}건 표시 / 목록 끝 · {n}건 |

## 상태와 오류

| 상황 | 제목 | 본문 |
| --- | --- | --- |
| 503 | 이적 정보를 불러오지 못했습니다 | 서버 점검 또는 장애일 수 있습니다. 잠시 뒤 다시 시도해 주세요. |
| 429 | 조회 요청이 많아 잠시 제한됐습니다 | {Retry-After}초 뒤 다시 시도할 수 있습니다. |
| 타임아웃 | 응답이 늦어 조회를 멈췄습니다 | 연결 상태를 확인하고 다시 시도해 주세요. |
| 통신 실패 | 네트워크에 연결할 수 없습니다 | 인터넷 연결을 확인한 뒤 다시 시도해 주세요. |
| 404(상세) | 이적 건을 찾을 수 없습니다 | 주소가 잘못됐거나 공개 목록에서 내려간 건입니다. |
| 결과 없음 | 이 시장에 연결된 이적 소식이 아직 없습니다 | 새 루머가 분석되면 최근 갱신순으로 나타납니다. |
| 지난 시장 결과 없음 | 이 시장에 남은 기록이 없습니다 | 보관 당시 이 구단과 연결된 이적 건이 없었습니다. |
| 시장 없음 | 추적 중인 이적시장이 없습니다 | 시장 추적이 시작되면 이곳에 구단별 소식이 쌓입니다. |
| 재조회 실패 | {오류 제목}. {시각}에 불러온 목록을 그대로 보여 줍니다. | 다시 시도 |
| 다음 페이지 실패 | 다음 목록을 불러오지 못했습니다. 위의 {n}건은 그대로입니다. | 다시 시도 |
| 버튼 | 다시 시도 | — |

## 갱신 상태 (`meta.pipeline_status`)

| 값 | 문구 |
| --- | --- |
| `ready` | {상대 시각} 갱신 (툴팁: 서버가 수집·분석을 마지막으로 정상 완료한 시각입니다.) |
| `delayed` | 갱신 지연 · 마지막 정상 갱신 {절대 시각} ({상대 시각}) / 새 루머가 반영되지 않았을 수 있습니다. |
| `unavailable` | 수집 중단 · 마지막 정상 갱신 {절대 시각} / 보이는 정보는 마지막 정상 갱신 기준입니다. |
| `unknown` | 갱신 상태를 확인할 수 없음 |
| 지난 시장 | {2026년 9월 2일} 보관된 기록 / 지난 시장은 읽기 전용입니다. 이후 새 소식은 반영하지 않습니다. |

## 서비스 성격

- 머리: "K리그 이적 레이더 · 독립 팬 서비스" (한국어 표시명은 브랜딩에서 확정 전, 임시)
- 읽는 법: "이 서비스는 커뮤니티와 언론의 이적 주장을 모아 정리합니다. 구단이나 리그의 공식 서비스가 아닙니다."
- 시각 표기: 한국 시간. 6일 이내만 상대 시각을 덧붙이고, 그보다 오래되면 절대 시각만. 올해가 아니면 연도를 붙인다.
