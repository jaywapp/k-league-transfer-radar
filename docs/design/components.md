# 컴포넌트 명세: 배송 조회 화면

모든 값은 [tokens.css](tokens.css)의 토큰 이름으로 적습니다. 동작 기준은 [시안](../ux-concepts/transfer-board/concept-02/)이며, 시안 코드와 이 문서가 다르면 이 문서를 따릅니다.

## 1. 공통 원칙

- **초록은 공식 확정 전용이다.** `--st-confirmed-bg`는 `official_confirmation`이 있는 이적 건에만 쓴다. `review_status = reviewed`(검토 완료)에는 쓰지 않는다.
- **주장은 늘 열린 모양이다.** 공식 확정이 아닌 단계는 점선 테두리, 빈 원, 옅은 채움으로 그린다. 꽉 찬 실선과 체크 표시는 공식 확정에만 쓴다.
- **검토 중인 주장은 진행으로 그리지 않는다.** 상충하는 새 주장이 검토 대기 중이면, 막대는 기존 단계에 그대로 두고 주장이 가리키는 위치에 "유령 표시"만 둔다.
- **색만으로 의미를 전달하지 않는다.** 단계 이름, 아이콘, 모양을 함께 쓴다.
- **신뢰도는 확률이 아니다.** 굵기, 점 개수, "신뢰도 낮음·보통·높음" 문구로만 표현하고 % 숫자를 쓰지 않는다.

## 2. 화면 구조

```text
┌ 상단 막대 ─────────────────────────────────────────────┐
│ 서비스명(독립 팬 서비스)   [이적시장 ▾] [구단 ▾] [읽는 법] [글 목록] │
├────────────────────────────────────────────────────────┤
│ 구단명  시즌·시장                                         │
│ [전체 14] [진행 중 10] [확정 2] [결렬·반박 2]   ← 보기 필터 │
│ ┌ 영입 8 ───────────────────────────────────────────┐ │
│ │       관심   접촉   협상   임박   확정   ← 역 이름(한 번)  │ │
│ │ 진행 중                                              │ │
│ │ (아바타) 이름/출발지   ●──●──◉──○──○   [결렬 주장 검토 중] │ │
│ │ 확정                                                │ │
│ │ 결렬·반박                                            │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌ 방출 6 … ┐                                            │
│ 갱신 상태 · 합성 데이터 표시(좌하단)          [상세 패널 →] │
└────────────────────────────────────────────────────────┘
```

| 폭 | 배치 |
| --- | --- |
| ≥1100px | 목록 최대 1240px 가운데 정렬. 상세 패널(폭 420px)이 오른쪽에 뜨면 목록은 `margin-right: 440px`로 비켜난다 |
| 600~1099px | 목록 전체 폭. 상세 패널은 목록 위 오른쪽에 겹쳐 뜬다(폭 420px, 최대 화면폭-32px) |
| <600px | 행이 두 줄로 접힌다(1줄: 아바타·이름·꼬리표, 2줄: 막대). 상세는 아래쪽 시트(좌우 8px, 최대 높이 62%) |
| 최소 320px | 가로 스크롤 없음. 이름은 말줄임 |

## 3. 조회 막대 `TrackBar`

| 요소 | 규칙 |
| --- | --- |
| 상자 | 높이 `--trk-height`(34px), 좌우 여백 9px. 선은 상자 높이의 64% 위치(위쪽 36%는 현재 위치 이름 자리) |
| 바탕 선 | 전체 폭, `--line`, 굵기 = 신뢰도(`--trk-w-low/medium/high` = 3/5/7px), 끝 둥글게 |
| 채움 선 | 0에서 현재 역까지, 색 = 현재 단계 색. 공식 확정은 3px 초록 반투명 후광 |
| 역 | 5개(관심·접촉·협상·임박·확정)를 0, 25, 50, 75, 100% 위치에. 지난 역: 12px 원, 단계 색으로 채움. 남은 역: 12px 원, `--surface` 채움 + `--line` 테두리 2px |
| 현재 위치 | 20px 원, 단계 색 채움 + 3px `--surface` 테두리 + 2px 단계 색 링 + 7px 18% 투명 후광. 위에 단계 짧은 이름(관심/접촉/협상/임박/확정, 11px 800) |
| 단계 미확인 | 채움 없음. 0% 위치에 20px 점선 빈 원 + "미확인" |
| 결렬설 | 채움은 0~56% 구간 단계 색 점선(6px 선, 4px 빈칸). 56% 위치에 × 아이콘(16px, `--st-failed`), 위에 "결렬". 이후 구간은 바탕 선만 |
| 유령 표시 | 검토 대기 상충 주장마다 1개. 22px 원, 2px 점선 `--rv-pending` 테두리, `--st-negotiation-bg` 70% 채움. 위치: 주장 단계의 역(결렬 주장은 92%, 확정 주장은 100%). 결렬 주장은 안에 × 12px. 2.2초 주기로 투명도 1↔0.45(모션 줄이기면 정지) |
| 큰 막대(상세) | 높이 40px, 위쪽 여백 18px, 같은 규칙 |

막대 전체를 버튼으로 만들지 않는다. 행 전체가 버튼이다.

## 4. 목록 행 `ParcelRow`

- 요소: `button`. 행 전체를 누르면 상세 패널이 열린다.
- 격자(≥600px): `40px | minmax(110px,190px) | 1fr | minmax(0,150px)`, 간격 12px, 위아래 여백 12px/10px.
- 칸 순서: 아바타 → 이름과 상대 구단 → 조회 막대 → 꼬리표.
- 이름: 15px 800, 한 줄 말줄임. 그 아래 12px `--muted`로 방향 화살표(영입 ↙ `arrow-down-left`, 방출 ↗ `arrow-up-right`)와 상대 구단 약칭. 상대 구단이 없으면 "출발 미상" 또는 "행선지 미상".
- 꼬리표(오른쪽 정렬, 여러 개 가능):
  - 검토 대기 상충 주장: `--rv-pending` 글자, `--st-negotiation-bg` 바탕, 시계 아이콘, "결렬 주장 검토 중"(주장 단계 짧은 이름 + " 주장 검토 중").
  - 반박됨: `--st-failed` 글자, `--st-failed-bg` 바탕, "반박됨".
- 상태: 기본, 마우스 올림(`--canvas` 바탕), 키보드 포커스(2.5px `--focus` 외곽선, 2px 띄움), 선택됨(`--focus` 8% 바탕), 결렬·반박 묶음은 이름을 `--muted`로.
- 접근 가능한 이름: "{선수}, {출발}에서 {도착}로, {단계 이름}, 신뢰도 {낮음|보통|높음}, {검토 상태}[, {주장} 주장 검토 중]".

## 6. 보기 필터 `ViewFilter`

- 버튼 4개: 전체 / 진행 중 / 확정 / 결렬·반박, 각 버튼에 건수. 높이 36px, 둥근 18px, 선택 시 `--ink` 바탕.
- 분류: 확정 = `stage = confirmed`. 결렬·반박 = `stage = failed` 또는 `review_status = refuted`. 나머지 = 진행 중.
- "전체"에서는 영입·방출 묶음 안에 진행 중 → 확정 → 결렬·반박 소제목(11.5px 800)을 두고 그 순서로 정렬하며, 같은 묶음 안에서는 `updated_at` 내림차순.
- 이 필터는 화면 안의 보기 전환이다. 서버 필터(`stage`, `confidence`, `review_status`, `q`)는 [작업지시서](work-order.md)의 2단계 범위다.

## 8. 조회 이력 `TrackingHistory`

최신순 세로 목록. 왼쪽 2px 세로선(`--line`), 항목마다 10px 점.

| 항목 종류 | 출처 데이터 | 점 | 제목 | 보조 |
| --- | --- | --- | --- | --- |
| 공식 발표 확인 | `official_confirmation.verified_at` | 초록 채움 | "공식 발표 확인"(초록, 인장 아이콘) | "서버가 구단 공식 발표를 확인했습니다." + 공식 발표 링크 |
| 단계 반영 | `history[]` | `--ink` 채움 | "{단계 이름} 반영" | "{reason} · {이전 짧은 이름}에서 이동" |
| 검토 중 주장 | `evidence[]` 중 `review_status = pending` 이고 `claimed_stage ≠ stage` | 점선 `--rv-pending` | "{짧은 이름} 주장 접수 · 검토 중"(주황) | 출처 · 주장 + "검토가 끝나기 전까지 현재 위치는 바뀌지 않습니다."(주황 12px 700) + 원문 링크 |
| 출처 주장 | 그 밖의 `evidence[]`(원문·관계 미확정) | 빈 원 | "{짧은 이름} 주장"(결렬 주장은 빨강) | 출처 · 종류 · 주장, 신뢰도, 원문 링크 |
| 구단 공식 발표(근거) | `evidence[]` 중 `source.kind = official` | 초록 채움 | "구단 공식 발표" | 같음 |
| 재게시 | `evidence[]` 중 `source_relation = repost` | 빈 원, 투명도 75% | "재게시" | 같음. **3건 이상 연속이면** "재게시 n건 펼치기 · 독립 근거로 세지 않음" 버튼으로 접는다 |

- 시각: 같은 시각이면 반영·공식 확인을 근거보다 위에 둔다. 표시는 한국 시간 절대 시각, 지난 시장에서는 상대 시각을 쓰지 않는다.
- 원문 링크: 새 창, 접근 가능한 이름 "{출처} 원문 (새 창)". `availability ≠ available`이면 링크 대신 "원문 삭제·접근 불가"(`--st-failed`, `link-break` 아이콘)를 표시하고 메타데이터는 남긴다.

## 10. 접근성

- 모든 행과 버튼은 키보드로 도달, 보이는 포커스 링.
- 막대와 아바타는 장식(`aria-hidden`)이고, 의미는 행의 접근 가능한 이름이 전달한다.
- 상단 "글 목록" 버튼은 같은 내용을 문장 목록으로 보여 준다(화면 낭독기·저시력 사용자용).
- 대비: 본문 4.5:1, 큰 글자·아이콘 3:1 이상(라이트·다크 모두). 토큰 값은 이 기준으로 골랐다.
- `prefers-reduced-motion`이면 유령 표시 깜빡임과 모든 전환을 끈다.
- 터치 대상 최소 36px(필터, 닫기), 행은 높이 56px 이상.
